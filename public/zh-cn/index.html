为 AI 智能体而生

Blowfish 附带一个智能体技能，教 Claude Code 等编程智能体安装、配置和使用本主题。
安装技能

Blowfish v3.5 已发布。 使用 npx blowfish-tools new <site> 创建新网站，或升级现有网站。

正在使用编程智能体？ 在 Claude Code 中运行 /plugin marketplace add nunocoracao/blowfish，然后运行 /plugin install blowfish@blowfish。对于会读取项目技能的其他智能体，将 blowfish 技能文件夹复制到网站中的 .claude/skills/blowfish/。
